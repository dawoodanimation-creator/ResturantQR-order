# Owner Portal Module (`/owner`)

Desktop-first administrative portal for restaurant owners and general managers.

### Key Responsibilities:
- Menu management: categories, items (with paisa formatting and Urdu RTL fields), photos.
- Modifier group management with shared usage counts.
- Branch and table CRUD, QR generation, token rotation, and printable A4 table tents/cards.
- Staff user management (username + temporary password creation, role scoping).
- Settings: billing mode, tax & service charge rates, KDS thresholds, brand color with WCAG contrast checker.
