# Kitchen Display System Module (`/kds`)

Designed for kitchen displays: 1920x1080 TV and 1280x800 tablet.

### Key Responsibilities:
- Dark theme with high contrast and >=64px touch targets. Readable from 2 metres.
- Oldest-first ticket queue with order numbers, elapsed timer, and modifiers.
- Restaurant-configured timer thresholds (amber at 10 min, red/late at 15 min).
- "Start cooking" -> "Mark ready" with a 10-second undo window.
- Compact / comfortable density toggle.
- Kitchen item sold-out toggle for the branch.
